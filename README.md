# spanish-app
## Apps

- **Habla Ya (Spanish):** `index.html`
- **Tara Usap (Tagalog):** `tagalog/`, an installable offline web app.

### Install Tara Usap on your phone

With GitHub Pages turned on for this repository (Settings → Pages → Deploy from a branch → `main`, `/(root)`):

1. Open **https://stevenjetton.github.io/spanish-app/tagalog/** in Safari (iPhone) or Chrome (Android).
2. iPhone: **Share → Add to Home Screen**. Android: **⋮ → Install app**.
3. Open it from the new icon. It works offline after the first visit (the "Hear it" audio links still need a connection).

Progress is saved on the phone. When `tagalog/index.html` changes, also change `VERSION` in `tagalog/sw.js`.
